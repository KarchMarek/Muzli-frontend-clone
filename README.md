# Muzli Frontend Clone (Classic Landing Page)

A simplified frontend recreation inspired by the classic Muzli landing page. This project was built for educational purposes to practice semantic HTML, CSS layout techniques, and recreating an existing interface as accurately as possible.

[🔗 View Live Preview](https://karchmarek.github.io/Muzli-frontend-clone/)

## 🚀 Tech Stack

- **HTML5** – Semantic page structure.
- **CSS3** – Custom styling, layout, typography, and responsive adjustments.

---

## 💡 What I Practiced

- **Semantic HTML** – Built a clean and accessible page structure.
- **Flexbox** – Centered and aligned navigation and hero section elements.
- **Typography & Spacing** – Matched the proportions and visual hierarchy of the original design.
- **Button Styling** – Recreated the call-to-action button using pure CSS.
- **Responsive Design** – Ensured the landing page adapts to different screen sizes.

---

## 🎯 Project Goal

The objective of this project was to recreate the classic Muzli landing page as closely as possible using only HTML and CSS.

The project focuses on:

- Replicating the overall visual appearance.
- Building a clean navigation bar.
- Creating a centered hero section with heading, description, and CTA button.
- Writing maintainable and well-structured HTML and CSS without external frameworks or JavaScript.

## 🛠️ How to Run Locally

1. Clone the repository:
